# 徒步轨迹裁剪器（Hiking Track Clipping）

像"图片裁剪"一样，自由裁剪两步路（2bulu）导出的徒步轨迹 KML——拖两个手柄圈住想保留/删除的路段，一键裁剪，里程爬升自动重算，导出的 KML 导回两步路或 Google Earth 严丝合缝。

纯本地桌面软件，数据不出本机。基于 Tkinter + matplotlib，零重依赖、完全离线。

## 功能特性

- **两种裁剪模式**：只保留 A→B 选区（掐头去尾）/ 删除 A→B 选区（去掉中途休息、绕路、打车段）
- **多次叠加**：裁完再裁，先掐头再去尾再抠中间，随时撤销/重做
- **双图联动选段**：上方轨迹平面图（等比例米投影）+ 下方海拔剖面图，两图 A/B 手柄同步
- **实时统计**：里程、时长、爬升/下降、点数随裁剪即时刷新
- **缩略图总览**：轨迹图右上角缩略图显示全程 + 当前视野红框
- **格式兼容**：支持两步路 `gx:Track` 格式（含时间戳、多段）与普通 `LineString` KML

### 交互操作

| 操作 | 效果 |
|---|---|
| 鼠标左键 | 设置 A 点（命中 A 手柄则拖动微调） |
| 鼠标右键 | 设置 B 点（命中 B 手柄则拖动微调） |
| 鼠标滚轮 | 缩放轨迹平面图（光标在图内以光标为中心，否则以视野中心为锚） |
| 方向键 ↑↓←→ | 平移轨迹平面图（步长 = 当前视野的 20%） |
| Home / 复原视图按钮 | 重置到全景 |
| Ctrl+Z / Ctrl+Y | 撤销 / 重做 |

## 快速开始

### 环境要求

- Python 3.12+
- 依赖：`matplotlib`、`tkinter`（Python 标准库自带）

### 安装依赖

```bash
pip install matplotlib
```

### 运行

```bash
python main.py 轨迹.kml
```

界面打开后，左键设 A、右键设 B 圈选路段，点击"只保留 A→B 选区"或"删除 A→B 选区"执行裁剪，最后点"导出 KML…"另存新文件（绝不覆盖原件）。

## 项目结构

```
kml_crop/
├── main.py              GUI 入口（Tkinter + matplotlib 双图联动）
├── core/                纯逻辑内核（不依赖 GUI，可单独测试）
│   ├── parser.py        解析 KML → 点列表（gx:Track 多段 / LineString）
│   ├── stats.py         里程(Haversine) / 时长 / 爬升下降(15点滚动均值滤波)
│   ├── cropper.py       区间模型 + 操作历史栈（撤销/重做）
│   └── exporter.py      以原始 XML 树为模板切片重写 + 起终点重建 + 元数据重算
├── verify_core.py       内核全链路验证（解析→统计→裁剪→导出→回读校验）
├── smoke_test_gui.py    GUI 冒烟测试（无头运行，模拟操作 + 截图）
└── 项目规划书.md         项目规划文档
```

## 统计算法说明

| 指标 | 方法 | 精度 |
|---|---|---|
| 里程 | Haversine 大圆距离（2D） | 与两步路元数据误差 1.3~1.7% |
| 爬升/下降 | 15 点滚动均值滤波后逐点累加 | 原始海拔直接累加虚高 40%+，滤波后误差 <2.3% |
| 时长 | 各保留段(末点-首点)求和，段间空缺不计 | — |

## 导出时自动完成

1. `gx:coord` 与 `when` 时间戳严格成对切片
2. 起点/终点标注按新轨迹首末点重建（坐标、海拔、时间描述）
3. Document 元数据重算：总里程/爬升/下降/起止时间/均速，步数与卡路里按里程等比缩放
4. 整段被裁空的 Placemark 自动移除
